# 第三周 Day 2 · Query Transformation 实验报告

## 一、实验目的

在 Day 1 的 RAG 检索基线基础上，尝试通过 Query Transformation（查询变换）改善检索效果，并比较原始查询与改写查询的 Top-3 检索结果。

重点验证：查询改写是否能够改善目标证据的排名，以及能否解决 case-03 多段证据召回不完整的问题。

## 二、实验环境与方法

- **知识库**：`学习计划.md`，共 25 个 Chunk
- **Embedding 模型**：BAAI/bge-m3
- **Top-K**：固定为 3
- **查询策略**：基于规则的 Query Normalization 和 Query Expansion
- **控制变量**：保持语料、Chunking、Embedding 模型和 Top-K 不变，仅改变检索 Query
- **生成模型**：本次未调用，仅比较检索结果

自行实现 `query_transform()`，使用术语映射表完成查询规范化，并复用原有 `retrieve()` 实现前后对照。

## 三、实验结果

### 1. B3 查询规范化

原始查询：第三个工程阶段

改写查询：B3 阶段

| 指标 | 改写前 | 改写后 |
|---|---|---|
| Top-3 Chunk | 12、15、19 | 15、14、13 |
| B3 所在 Chunk 排名 | Top-2 | Top-1 |
| B3 相似度 | 0.4813 | 0.5417 |

目标 Chunk 15 的排名从第二提升到第一，但改写前后均已进入 Top-3。

### 2. B4 查询规范化

原始查询：第四个工程阶段

改写查询：B4 阶段

| 指标 | 改写前 | 改写后 |
|---|---|---|
| Top-3 Chunk | 16、15、19 | 16、15、17 |
| B4 所在 Chunk 排名 | Top-1 | Top-1 |
| B4 相似度 | 0.5332 | 0.5341 |

目标 Chunk 16 的排名没有变化，改写未带来明显的检索质量改善。

### 3. 八道开发题的初始对照

使用最初的两条术语映射规则，重新运行 Day 1 的八道 dev 题。

结果：

- 成功执行：8/8
- 实际触发改写：0/8
- Top-3 排名变化：无

说明当前规则未覆盖这些问题，不能据此判断 Query Transformation 整体无效。

### 4. case-03 查询扩展

原始查询：B线有哪些阶段及其时长？

扩展查询：B 线中，B1、B2、B3、B4、B5 分别是什么阶段？各阶段的学习时长是多少？

| 指标 | 改写前 | 改写后 |
|---|---|---|
| Top-1 | Chunk 13（B1） | Chunk 17（B5） |
| Top-2 | Chunk 14（B2） | Chunk 15（B3） |
| Top-3 | Chunk 17（B5） | Chunk 13（B1） |
| 阶段证据覆盖 | 3/5 | 3/5 |
| 缺失阶段 | B3、B4 | B2、B4 |

改写后 B3 进入 Top-3，但 B2 被挤出，整体证据覆盖仍为 3/5，没有实现完整召回。

该规则是针对已知失败案例设计的探索性规则，不代表其对其他查询具有普遍效果。

## 四、实验结论

本次实验说明：

1. Query Transformation 能够改变向量相似度和检索排名。
2. 相似度提高并不等于正确证据的召回数量增加。
3. 查询改写可能使部分相关 Chunk 进入 Top-3，同时挤出其他必要证据。
4. case-03 的五个阶段分散于五个独立 Chunk，固定 Top-K=3 无法通过这五个单阶段 Chunk 获取完整答案。
5. 规则覆盖范围直接影响改写策略是否被触发。

**最终结论：本次查询改写改善了部分目标 Chunk 的排名，但没有证明整体召回质量提升，也没有解决 case-03 的完整证据缺失问题。**

## 五、局限与后续方向

- 测试数据规模较小，无法证明策略的普遍有效性。
- 当前规则数量有限，不能覆盖多数自然语言表达。
- 本次没有运行生成模型，不能直接推断最终回答质量。
- 后续可结合 Top-K、Chunking、BM25、Hybrid Search 和 Reranking 等方法继续研究检索问题，但需要分别进行控制变量实验。

## 六、学习收获

通过本次实验，理解了 Query Normalization、Query Expansion、Query Drift 和 Controlled Experiment。

最重要的收获是：**RAG 优化不应只追求相似度分数提高，而应根据真实证据判断检索是否满足回答需求。**
