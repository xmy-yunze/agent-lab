## case-06｜这份双线学习方案，并不是要把算法岗和开发岗两条路线都练到可以直接入职，对吗？

**Top-K：** 3

### Top-1 · Chunk 3 · 相似度 0.7519

学习计划 · Java 后端与 AI / Agent 双线发展 > 零、学长说「两条线都要学」，怎么理解才对
### 「两条都要学」≠「两条都要练到能就业」

这一点必须说清楚，否则 4 个月后可能两边都半途而废：

- **算法线**的评价标准是**论文、创新、影响力**。入场券是实验能力和学术产出，主力是科班 ML 硕博。而且它岗位只是「中等」，竞争却是「很激烈」—— 典型的红海。
- **开发线**的评价标准是**稳定性、业务价值、工程能力**。P99、QPS、成本、并发、可用性 —— **这些词你已经用了几年了**。而且它岗位最多、竞争反而「适中」。

**用后端功底去拼算法线的入场券，是拿短板拼别人长板；把后端功底用在开发线上，是拿长板打别人的短板。**

### Top-2 · Chunk 2 · 相似度 0.6987

学习计划 · Java 后端与 AI / Agent 双线发展
## 零、学长说「两条线都要学」，怎么理解才对

AgentGuide 把 Agent 方向的岗位分成两条线：

| | 算法工程师线 | 开发工程师线 |
|---|---|---|
| 核心工作 | 算法创新、论文研究 | 系统搭建、业务落地 |
| 日常任务 | 读论文、设计算法、跑实验、做消融、写论文、开源贡献 | 写代码、优化系统、对接业务、解决问题、性能调优、监控告警 |
| 产出形式 | 论文发表、算法库、开源项目、专利 | 生产系统上线、业务指标提升、用户满意度提高 |
| 评价标准 | 算法性能提升（+15% 准确率）、创新性、影响力 | 系统稳定性（P99 延迟 < 500ms）、业务价值（成本降低 40%）、工程能力（QPS、并发、可用性） |
| 岗位数量 | ⭐⭐⭐ 中等 | ⭐⭐⭐⭐⭐ **最多** |
| 竞争激烈度 | ⭐⭐⭐⭐⭐ **很激烈** | ⭐⭐⭐ **适中** |
| 薪资天花板 | ⭐⭐⭐⭐⭐ 很高（60-200 万） | ⭐⭐⭐⭐ 较高（40-80 万） |
