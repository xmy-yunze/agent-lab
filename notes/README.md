# notes · 笔记放这里

## 记什么

**不要抄知识点。** 知识点在文档里，抄一遍不会变成你的。

只记这三类：

1. **我的理解** —— 用自己的话把这个机制讲一遍。讲不顺的地方，就是没懂的地方。
2. **踩过的坑** —— 报错原文、我卡在哪、最后怎么通的。这类最值钱，因为下次一定还会遇到。
3. **跟后端的对应关系** —— 「这个东西相当于后端的 XX」。攒多了就是一套现成的知识迁移框架。

## 怎么命名

一个主题一个文件，比如 `agent-loop.md`、`上下文与记忆.md`。不要按日期拆，按主题拆，方便以后翻。

## 一个判断标准

三个月后回来看，如果这笔记只让我想起「有这么个概念」，那就是白记了；如果它能让我**直接上手做**，就是记对了。
